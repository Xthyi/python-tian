一、你要记住的三个地址

① 我的仓库 https://github.com/Xthyi/python-tian ← 最重要的一个，代码都在这儿
② 我的主页 https://github.com/Xthyi ← 那片绿格子（贡献图）在这里
③ GitHub 首页 https://github.com ← 信息流/推荐，新手进去容易懵
直接进 github.com 和进仓库链接，看到的东西不一样：
  • github.com（首页）：登录后会看到别人的动态、推荐仓库、全英文的导航栏。这里几乎没用，别在这儿找代码。
  • 仓库链接（①）：直接落到你自己的项目页面，看到文件列表和 README。这才是你要天天看的那一页。
  • 个人主页（②）：你的仓库列表 + 底部那张提交热力图（绿格子）。

四、进去之后你只要会这三件事

  1. 看自己的代码：打开仓库链接 → 默认就在 Code 页 → 点文件夹进去 → 点文件名就能看源码。
  2. 看自己学了多久：打开主页链接 → 往下滚 → 那片绿色格子就是你的提交记录，一天一次。
  3. 更新代码：不用在网页上操作。回 Mac 双击 提交到GitHub.command，或者终端跑 gpush "写了什么"，刷新网页就能看到新的提交。

⚠️ 网页打不开很正常（国内访问不稳定），不影响 git 推送。真急着看就用手机热点。
