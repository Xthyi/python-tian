## 一、输出与输入

```python
print("你好")                  # 输出
print("a", "b")                # 多个值，逗号自动加空格
print(f"我叫{name}，{age}岁")    # f-string：最常用，记住这个就行

name = input("请输入名字：")     # 输入，返回的一定是【字符串】
age = int(input("年龄："))       # 要数字就自己转
```

**易错点**：`input()` 拿到的永远是字符串，不转 `int` 直接比大小会报错。

## 四、分支

```python
if score >= 90:
    print("优")
elif score >= 60:       # 是 elif，不是 else if

    print("不及格")
```

## 五、循环

```python
# for：次数已知 / 遍历用
for i in range(5):        # 0 1 2 3 4
    print(i)

for i in range(1, 6):     # 1 2 3 4 5
    print(i)

for i in range(5, 0, -1): # 5 4 3 2 1，第三个参数是步长
    print(i)

for ch in "abc":          # 直接遍历字符串
    print(ch)

# while：条件满足就一直转，次数未知用
n = 0
while n < 5:
    n += 1                # 没有这行就死循环！

# 两个跳转
break      # 整个循环结束
continue   # 跳过这一次，继续下一轮
```

## 六、列表 list（最常用）

```python
a = [3, 1, 2]
a.append(9)      # 末尾加一个        -> [3, 1, 2, 9]
a.insert(0, 8)   # 指定位置插入
a.remove(1)      # 删掉值 1（按值）
a.pop()          # 弹出最后一个（按位置）
a.sort()         # 就地排序（改自己）
sorted(a)        # 返回新列表（不改自己）
len(a)           # 长度
a[0]  a[-1]      # 第一个 / 最后一个
a[1:3]           # 切片，左闭右开
max(a) min(a) sum(a)
9 in a           # 判断在不在，返回 True/False

# 列表推导式：一句话生成列表，很显水平
squares = [x * x for x in range(1, 6)]   # [1, 4, 9, 16, 25]
evens = [x for x in a if x % 2 == 0]     # 带筛选
```

## 七、字典 dict

```python
stu = {"name": "小明", "age": 19}
stu["age"]              # 取值，键不存在会报错
stu.get("sex", "未知")   # 安全取值，没有就给默认值
stu["city"] = "杭州"     # 新增 / 修改
del stu["city"]         # 删除

stu.keys()    # 所有键
stu.values()  # 所有值
stu.items()   # 所有键值对，遍历时最常用

for k, v in stu.items():
    print(k, v)

"name" in stu  # 判断键在不在
```

## 八、函数

## 十三、报错怎么自己搞定（比问老师快）

按顺序做这三步：

1. **看最后一行**。报错信息最后一行才是真正的病根，前面的都不用看。
   - `SyntaxError` → 语法写错了，重点查：少冒号、少括号、中文标点
   - `IndentationError` → 缩进不对
   - `NameError` → 变量名打错，或者还没定义就用了
   - `TypeError` → 类型不对，比如字符串和数字相加
   - `ValueError` → 值不对，比如 `int("abc")`
   - `IndexError` → 下标越界
   - `KeyError` → 字典里没这个键
2. **看行号**，跳到那行前后五行。
3. **`print` 大法**：在可疑位置 `print(变量)`，看它到底等于什么。九成问题一眼看穿。

**最高频的坑**：中文标点。`（）` `，` `"` 全角字符看起来一样，程序不认。检查方法：报 `SyntaxError` 且看着没问题，就是这类。
