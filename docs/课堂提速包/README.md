# 课堂提速包

给「第一次带电脑上课」准备的四件套。按顺序用，5 分钟上手。

## 用法（三步）

**第 1 步 · 进教室坐下，先自检**

终端里跑：

```bash
cd ~/WorkBuddy/2026-10-09-10-43-23/课堂提速包
python3 01_环境自检.py
```

全绿就安心上课。有红项按提示修，别等老师讲到一半才发现跑不了。

**第 2 步 · 把速查卡开着放旁边**

`02_课堂速查卡.md` —— 老师讲到哪个语法，抬眼扫一下就够了。
别人翻书找页码的时候，你已经在敲代码了。

**第 3 步 · 提前跑一遍下一课**

```bash
python3 03_预习_列表与字典.py
```

这份预习覆盖列表、字典、遍历、函数、综合统计器。
上课老师讲到这儿，你的状态是「复习」而不是「首学」，差距就是这么拉开的。

**收尾 · 每节课留痕**

`04_课堂笔记模板.md` 复制一份，下课前 5 分钟填完，代码提交一次 git。
一学期下来别人手里是一堆散文件，你手里是一个能拿得出手的仓库。

## 文件清单

| 文件 | 用途 |
|---|---|
| `01_环境自检.py` | 5 秒确认电脑能上课（Python / Git / 中文 / 目录可写 / 标准库） |
| `02_课堂速查卡.md` | 一页语法 + 快捷键 + 报错自查，课上随手查 |
| `03_预习_列表与字典.py` | 下一课内容提前跑通，含 4 道课后练习 |
| `04_课堂笔记模板.md` | 每节课一份，含 git 提交动作 |

## 想再快一步？

在终端执行这几条，让「上课写代码」变成肌肉记忆：

```bash
# 1. 把预习脚本放进你的学习仓库，形成习惯
cp 03_预习_列表与字典.py ~/Documents/python-practice/basics/03_list_dict.py

# 2. 建个练习目录（README 里规划了但还没建）
mkdir -p ~/Documents/python-practice/exercises

# 3. 一键提交（以后每节课结束跑一次）
cd ~/Documents/python-practice && git add -A && git commit -m "课堂练习"
```

> 注意：占位符 `-m "课堂练习"` 每次记得改成具体内容，比如 `-m "第5课：列表与字典"`。
> 提交记录写得越具体，期末你回头看越值钱 —— 它就是你的学习轨迹。
