## 第一次开机：把 D 盘弄出来（5 分钟，就是老师要教的内容本身）

> **没弹"初始化磁盘"的提示是正常的**，Windows 有时不弹。直接走下面的步骤，殊途同归。

1. 按 **⌘ + R**（等于 Windows 的 Win + R），输入 `diskmgmt.msc`，回车 —— 直接打开**磁盘管理**
   （或者：右键屏幕左下角的开始按钮 → 磁盘管理）
2. 下半部分会看到：**磁盘 0** 是 C 盘；**磁盘 1** 显示"未分配"（黑色长条）
3. 如果磁盘 1 左边写着"**未初始化**"：右键"磁盘 1"三个字 → **初始化磁盘** → 选 **GPT** → 确定
4. 右键右边那块"**未分配**"黑色区域 → **新建简单卷** → 一路下一步
5. 到"分配驱动器号"那步，选 **D** → 继续 → 文件系统 NTFS → 完成
6. 打开"此电脑"—— C 盘、D 盘都有了

> 这一步就是老师在讲的东西。你在虚拟机里先做一遍 = 提前学会了，还不心疼。

## 想确认自己装的是不是 Windows 11？

按 **⌘ + R**，输入 `winver`，回车。弹出的窗口第一行就写着"**Windows 11**"和具体版本号。

不用查也能看出来：**任务栏图标居中**就是 Windows 11 的标志（Windows 10 的任务栏是靠左的）。你的就是 Win 11。

## Mac 和 Windows 怎么传文件（老师不教，但你会）

**方法 A：共享文件夹（已配置好）**
- 开"此电脑"，找 **DavWWWRoot** 或 **Spice client (Y:)** 这样的网络位置
- 点进去就是 Mac 上共享的文件夹，直接拖文件，两个系统之间互传

**方法 B：微信 / QQ 文件传输助手**
- 两个系统登同一个号，发给"文件传输助手"，另一边就能收
- 简单粗暴，没有门槛，实在不行就这个

## 虚拟机的三个坑（记住能救命）

1. **关机必须从 Windows 里关**（开始 → 电源 → 关机）。
   直接叉掉 UTM 窗口 = 直接拔电源，虚拟磁盘可能损坏，整个系统就没了。
2. **别在 Windows 里存唯一一份重要文件**。
   虚拟机本质上是一个大文件，哪天误删就全没了。重要代码走 GitHub。
3. **卡了别慌，虚拟机就是比真机慢**。
   真死机了：UTM 顶部菜单有光驱/电源按钮，可以强制重启。
